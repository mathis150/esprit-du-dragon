# 📜 Créatures mythiques

Ce sont des créatures dont les voir représente l'exploit d'une vie, et dont leurs matériaux sont souvent d'une rareté, elle aussi, très élevé.

Mais le danger qu'ils représentent est aussi plus que significatif, ayant déjà prouvé pourquoi nous les disions "mythiques".
