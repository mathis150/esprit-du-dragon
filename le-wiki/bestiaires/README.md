# 🐉 Bestiaires ⏳

Le bestiaire rassemble l'ensemble des créatures connu du lore de "l'Esprit du Dragon", ils vous permettront d'avoir une base pour connaître les différentes créatures, et pour les chasseurs, les moyens de connaître leurs différents points faibles.
